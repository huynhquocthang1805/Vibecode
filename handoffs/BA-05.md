## API / component công khai

Các export mới chỉ thuộc script BA-05, không thay API trong docs/10:

```ts
export const DEFAULT_SEED = 20261101;
export const MOCK_CAMPAIGNS: readonly Campaign[];
export type GenerateOptions = {
  seed?: number;
  today?: string;
  endDate?: string;
  days?: number;
  campaignCount?: number;
  profile?: 'demo' | 'campaign' | 'stress';
};
export function mulberry32(seed: number): () => number;
export function generate(n: number, options?: GenerateOptions): DailyEntry[];
export function auditDataset(entries: DailyEntry[], today: ISODate, expectedCount: number): void;
export function eventFactors(date: ISODate): { reach: number; conversion: number; event: string };
export function summarize(entries: DailyEntry[]): Totals & { kpis: Kpis };
export function demoEvidence(entries: DailyEntry[]): {
  early: Totals & { kpis: Kpis };
  fatigue: Totals & { kpis: Kpis };
  late: Totals & { kpis: Kpis };
};
export async function main(args: string[]): Promise<void>;
```

`n` là số dòng. `days` và `campaignCount` kiểm tra tương thích số dòng; hai preset cố định 30×1 và 730×3. `source='mock'`, `id=campaignId|date`, `createdAt=updatedAt=0` như quy ước adapter BA-01. Import script không tự sinh/ghi file. Không import script chứa Node I/O vào client.
