## Cách dùng cho người nhận

1. Cập nhật branch BA-05 từ main sau khi lưu công việc hiện tại; giải nén gói patch ở thư mục ngoài và đối chiếu diff trước khi chép file.
2. Chạy trong Windows PowerShell tại root repository:

```powershell
npm.cmd ci
npm.cmd run gen:mock -- --seed 20261101 --today 2026-11-02 --end-date 2026-11-01
npm.cmd run test -- tests/integration/gen-mock.test.ts tests/integration/gen-mock.review.test.ts
npm.cmd run check
```

3. Đối chiếu kết quả fixture sau `gen:mock`, thời gian đo và test output; nếu không giống, **giữ lại log lỗi và điều tra**, không sửa đáp án test để đạt PASS.
4. Nếu chỉ muốn dùng mốc ngày tự động, chạy `npm.cmd run gen:mock` (mỗi ngày sẽ ra JSON khác); muốn đối chiếu hash ở trên thì phải dùng **cùng** seed/mốc 2026-11-02.
