### Lệnh cần chạy và lưu output trước khi xin nghiệm thu

```powershell
# Đứng ở root repository và đúng branch BA-01
git branch --show-current
git status --short
git diff --name-only origin/main...HEAD

# Đếm ca, kiểm ID, kiểm cấu trúc cơ bản; không thay thế test runtime
node -e "const fs=require('fs');const x=JSON.parse(fs.readFileSync('src/fixtures/edge-cases.json','utf8'));if(!Array.isArray(x))throw Error('Expected JSON array');const ids=x.map(v=>v.id);const missing=x.filter(v=>!v.id||!v.kind||!Object.hasOwn(v,'input')||!Object.hasOwn(v,'expect'));console.log({total:x.length,uniqueIds:new Set(ids).size,missingFields:missing.map(v=>v.id)});if(x.length<30||new Set(ids).size!==x.length||missing.length)process.exitCode=1"

# Chạy bộ kiểm tra của dự án
npm run check
```

Sau khi có log thực tế, ghi lại số ca đã kiểm, số pass/fail/blocked, tên script và kết quả cùng commit SHA. **Không tự coi kết quả `npm run check` xanh (nếu có) là bằng chứng toàn bộ fixture pass với logic thật:** trong giai đoạn skeleton có thể vẫn còn stub.
