# Change Requests

Agent cần đổi file KHÔNG thuộc quyền sở hữu của mình (đặc biệt `src/types/domain.ts`) ghi vào đây. Techlead xử lý, đánh dấu `[x]` + quyết định.

Mẫu (bỏ thụt đầu dòng khi dùng):

    - [ ] **CR-001** · từ `<role>` · file `<path>` · <mô tả thay đổi> · lý do: <…> · ảnh hưởng: <roles> · Quyết định: _(techlead)_
