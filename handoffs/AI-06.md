## Đã làm
- Triển khai hook React `useInsights(snapshot)` chạy phía client (`'use client'`).
- Quản lý đầy đủ 5 trạng thái: `idle | loading | success | fallback | error`.
- Cơ chế bộ nhớ đệm client qua `localStorage` (`kpi-dash:ai-cache`): lưu tối đa 20 mục, TTL 24 giờ, tự động dọn dẹp mục cũ nhất khi vượt kích thước.
- Tự động gọi API khi có snapshot mới, hoặc khi số liệu thay đổi > 5% sau khoảng debounce 60s.
- Cung cấp hàm `refresh()` cho phép người dùng bấm thử lại/làm mới và bỏ qua cache client.
- Quản lý vòng đời request chặt chẽ bằng `AbortController`, tự động hủy request cũ khi component unmount hoặc khi snapshot thay đổi.
- Thiết kế an toàn: hook trong render tree tuyệt đối không bao giờ throw lỗi, trả về `data: null` và `status: 'idle'` ngay khi `snapshot` là null mà không gây cascading render.

## API / component công khai
```ts
export type InsightStatus = 'idle' | 'loading' | 'success' | 'fallback' | 'error';
export interface UseInsightsResult {
  data: InsightResponse | null;
  status: InsightStatus;
  error?: InsightError;
  refresh(): void;
}
export function useInsights(snap: AnalyticsSnapshot | null): UseInsightsResult;
```
